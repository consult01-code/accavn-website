File XML hóa đơn điện tử: đọc hiểu cấu trúc và vì sao phải lưu

Đọc hiểu cấu trúc file XML hoá đơn điện tử, phân biệt với PDF và lý do phải lưu XML đầy đủ.

Nhiều doanh nghiệp chỉ lưu bản PDF hoá đơn vì dễ xem, dễ in, rồi bỏ qua file XML đi kèm. Thực ra file XML hóa đơn điện tử mới là dữ liệu gốc mang chữ ký số; PDF chỉ là bản thể hiện để con người đọc. Bài viết của ACCA Consulting Vietnam giải thích các khối dữ liệu trong file XML, cách mở và đọc nhanh, và vì sao phải lưu đầy đủ.

1. File XML hóa đơn điện tử và bản PDF khác nhau thế nào

XML (eXtensible Markup Language) là định dạng văn bản có cấu trúc, mỗi thông tin nằm trong một cặp thẻ có tên. Hoá đơn điện tử theo NĐ 123/2020 (sửa đổi bởi NĐ 70/2025) được lập theo định dạng dữ liệu chuẩn do cơ quan thuế quy định, và file XML là nơi chứa dữ liệu đó.

Khi chỉ còn PDF, doanh nghiệp khó chứng minh dữ liệu gốc nếu có tranh chấp hoặc khi cơ quan thuế yêu cầu. Vì vậy quy trình nhận hoá đơn nên coi XML là bắt buộc, PDF là bổ sung.

2. Các khối dữ liệu trong file XML hóa đơn

Tên thẻ dưới đây là các tên thường thấy theo định dạng chuẩn của cơ quan thuế; tên và vị trí có thể khác giữa các phiên bản định dạng, nên hãy đối chiếu với file thực tế.

3. Cách mở và đọc nhanh file XML

Muốn đọc nhiều file cùng lúc, Excel có chức năng lấy dữ liệu từ XML qua Power Query (Get Data → From File → From XML). Khi đã dựng truy vấn cho một file, bạn có thể mở rộng để gộp cả thư mục và đối chiếu với sổ sách.

4. Dùng AI hỗ trợ đọc XML mà không lộ dữ liệu

Trợ lý AI giỏi giải thích cấu trúc và viết mã xử lý XML. Cách an toàn là đưa cho AI một file mẫu đã thay toàn bộ tên, MST, số tiền bằng dữ liệu giả, hoặc chỉ mô tả tên thẻ. Mã do AI viết sẽ chạy trên máy doanh nghiệp với dữ liệu thật.

Không tải hàng loạt file XML thật lên công cụ AI công cộng: file chứa MST, tên đối tác, giá trị giao dịch và tài khoản ngân hàng. Xem thêm cách ẩn danh dữ liệu kế toán trước khi dùng AI.

5. Vì sao phải lưu XML và lưu thế nào

Chứng từ kế toán dùng trực tiếp để ghi sổ và lập báo cáo tài chính phải lưu tối thiểu 10 năm (Luật Kế toán 2015). Với hoá đơn điện tử, lưu XML là cách giữ được dữ liệu gốc có chữ ký. Dung lượng XML nhỏ nên chi phí lưu trữ không đáng kể.

Theo kinh nghiệm của ACCA Consulting Vietnam, doanh nghiệp thiếu XML thường phải xin lại hàng loạt từ nhà cung cấp khi bị kiểm tra, mất nhiều thời gian. Xem thêm lưu trữ chứng từ điện tử đúng cách.

Kho hoá đơn chỉ có PDF, thiếu XML? ACCA Consulting Vietnam rà soát và sắp xếp lại kho chứng từ trong dịch vụ kế toán tại TP.HCM, kiểm tra sơ bộ miễn phí. Nhận tư vấn.

Câu hỏi thường gặp

Mở file XML bằng Notepad rồi lưu lại có sao không?

Có thể làm thay đổi nội dung hoặc định dạng mã hoá, khiến chữ ký số không còn hợp lệ. Chỉ mở để xem; nếu cần, hãy làm việc trên bản sao.

Nhà cung cấp chỉ gửi PDF thì làm sao?

Đề nghị nhà cung cấp gửi kèm XML, hoặc tải từ trang tra cứu hoá đơn của họ hoặc cổng hoá đơn điện tử nếu có chức năng. Nên đưa yêu cầu gửi XML vào điều khoản hợp đồng mua hàng.

Phần mềm kế toán có đọc được XML không?

Nhiều phần mềm kế toán có chức năng nhập hoá đơn từ XML, giúp giảm nhập tay. Hãy kiểm tra tài liệu của phần mềm doanh nghiệp đang dùng.

ACCA Consulting Vietnam có hỗ trợ lưu trữ, nhập liệu hoá đơn XML không?

Có. Trong dịch vụ kế toán trọn gói, ACCA nhận hoá đơn XML, kiểm tra thông tin, ghi sổ và sắp xếp kho chứng từ theo kỳ để doanh nghiệp tra cứu khi cần.

Dữ liệu hoá đơn gốc được lưu đúng, tìm lại dễ
