Power Query cho kế toán: gộp nhiều file sổ chi tiết trong vài phút

Gộp 12 file sổ chi tiết tháng bằng Power Query: 7 bước làm một lần, các tháng sau chỉ cần thả file vào thư mục và làm mới.

Cuối năm, bạn cần một bảng tổng hợp chi phí cả năm từ 12 file sổ chi tiết tháng. Cách quen thuộc là mở từng file, copy, dán, sửa tiêu đề, mất cả buổi và dễ sót dòng. Bài này hướng dẫn dùng Power Query kế toán để gộp toàn bộ file trong một thư mục thành một bảng sạch, làm một lần và chỉ cần bấm làm mới cho các tháng sau. Quy trình dưới đây là cách ACCA Consulting Vietnam gợi ý cho kế toán nội bộ muốn tự động hoá việc tổng hợp mà chưa cần phần mềm mới.

1. Power Query là gì và vì sao kế toán nên dùng

Power Query (trong Excel nằm ở thẻ Data, nhóm Get & Transform Data) là công cụ lấy và làm sạch dữ liệu có sẵn trong Excel 2016 trở lên và Microsoft 365. Điểm khác biệt so với công thức: Power Query ghi lại các bước bạn thao tác. Lần sau có dữ liệu mới, nó chạy lại đúng các bước đó.

  • Gộp nhiều file cùng cấu trúc trong một thư mục.
  • Xoá dòng tiêu đề thừa, dòng trống, dòng cộng.
  • Đổi kiểu dữ liệu ngày, số tiền đồng loạt.
  • Không sửa file gốc: dữ liệu nguồn được giữ nguyên.

2. Chuẩn bị file nguồn

Phần lớn lỗi khi gộp đến từ việc một tháng có ai đó đổi tên cột hoặc thêm cột. Nếu file xuất từ phần mềm kế toán, hãy dùng cùng một mẫu xuất cho mọi tháng. Quy tắc đặt tên file có trong bài quy tắc đặt tên file, thư mục chứng từ.

3. Gộp 12 file trong 7 bước

Cột Source.Name (tên file) được Power Query giữ lại khi gộp. Từ cột này, dùng Split Column hoặc Extract để lấy ra kỳ “2026_03”, giúp bạn biết mỗi dòng thuộc tháng nào mà không cần cột tháng trong file gốc.

4. Làm mới khi có file tháng mới

Đây là phần đáng giá nhất. Tháng 4 có file mới, bạn chỉ cần lưu “SCT_2026_04.xlsx” vào cùng thư mục, mở file tổng hợp và bấm Data → Refresh All. Power Query chạy lại 7 bước trên tất cả file, kể cả file mới.

Theo ví dụ trên, từ tháng thứ hai mỗi tháng tiết kiệm gần một giờ, và quan trọng hơn là giảm rủi ro sót dòng khi dán. Nếu thư mục đổi vị trí (ví dụ chuyển sang ổ dùng chung), vào Data → Get Data → Data Source Settings để đổi đường dẫn.

5. Lỗi thường gặp và mẹo dùng Power Query kế toán

Sau khi có bảng gộp sạch, bước tiếp theo tự nhiên là phân tích bằng Pivot Table phân tích chi phí. Nếu dữ liệu nguồn là sao kê ngân hàng, xem thêm chuẩn hoá sao kê ngân hàng trên Excel.

Nhờ trợ lý AI hỗ trợ Power Query

Power Query có ngôn ngữ công thức riêng (thường gọi là ngôn ngữ M). Bạn có thể nhờ trợ lý AI giải thích hoặc viết bước tuỳ chỉnh, ví dụ: “Giải thích từng dòng đoạn mã M sau và chỉ ra bước nào sẽ lỗi nếu file tháng mới thiếu cột Ghi chú: [dán mã từ Advanced Editor]”. Mã M chỉ chứa cấu trúc bước và tên cột, nhưng hãy kiểm tra để chắc không có đường dẫn thư mục chứa tên khách hàng hay dữ liệu nhạy cảm trước khi dán lên công cụ AI công cộng.

Câu hỏi thường gặp

Power Query có sẵn trong Excel của tôi không?

Excel 2016 trở lên và Microsoft 365 trên Windows có sẵn Power Query ở thẻ Data. Excel 2010, 2013 cần cài thêm phần bổ trợ. Tính năng trên máy Mac có thể hạn chế hơn, nên thử trước.

Power Query có làm thay đổi file sổ chi tiết gốc không?

Không. Power Query chỉ đọc file nguồn và tạo bảng kết quả trong file tổng hợp. File gốc giữ nguyên.

Có thể gộp file từ Google Drive, OneDrive không?

Có thể nếu thư mục được đồng bộ về máy hoặc dùng kết nối phù hợp với nơi lưu trữ. Cách đơn giản nhất là đồng bộ thư mục về máy rồi chọn From Folder.

ACCA Consulting Vietnam có cung cấp dữ liệu sổ sách dạng Excel cho doanh nghiệp không?

Có. Khi dùng dịch vụ kế toán, doanh nghiệp có thể yêu cầu sổ chi tiết, báo cáo dạng Excel theo kỳ; phạm vi cụ thể được thống nhất trong hợp đồng.
